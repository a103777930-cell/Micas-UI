## 使用与页面用途

先下载并复制工作副本，用 Microsoft PowerPoint 打开；不要覆盖本仓库的正式文件。使用“新建幻灯片/版式”选择母版中的布局。字体、图片裁剪和继承样式应保留；中文内容需检查字体替代和溢出。修改模板字节时新增版本，不替换 V1.0.0。
