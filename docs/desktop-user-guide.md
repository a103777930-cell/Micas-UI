# Micas Document Converter 本地桌面版 V1

这是 PPTX 转换工具；暂不支持 Word、Excel 或旧版 .ppt。文件转换在本机进行，应用不包含网络请求、模型 API、遥测或云端服务。无需 Python、GitHub 账号或命令行。

## 下载、安装与启动

请从公司管理员取得与你电脑系统和处理器架构一致的 ZIP。开发分支的 CI 产物由管理员在 GitHub Actions 的 **Build desktop apps → 成功的运行 → Artifacts** 下载分发，普通员工无需访问 GitHub。Actions 下载通常需要 GitHub 登录；本版尚未提供免登录的公开下载站。

- **Windows**：解压整个 `MicasDocumentConverter-Windows.zip` 到本地文件夹。双击其中的 `MicasDocumentConverter.exe`。必须保留同文件夹内的 `_internal` 资源目录；不要只复制 exe。该版本为免安装便携版，没有安装向导。
- **macOS**：解压 `MicasDocumentConverter-macOS.zip`，将 `MicasDocumentConverter.app` 拖到“应用程序”，双击打开。构建针对 Runner 的处理器架构，下载时查看产物名中的 ARM64/X64；不是 Universal 应用。

这是未签名、未公证的测试版。Windows 可能显示 SmartScreen“无法识别的应用”，macOS 可能提示无法验证开发者。请先核验来源，按公司 IT 政策处理或联系管理员；不要关闭系统安全防护。企业正式分发前需要 Windows 代码签名及 macOS Developer ID 签名和公证。没有在真实员工电脑上验证过的构建不得称为已完成兼容性认证。

## 转换步骤

1. 双击打开应用，点击“选择文件”，或把一个 `.pptx` 拖到“原始 PPTX”输入框。
2. 查看已选文件完整路径。默认输出目录与原稿相同；也可点“选择目录”。
3. 点击“开始转换”。状态条显示处理中；可移动窗口，等待完成。进度条表示任务正在运行，不表示百分比。转换期间不能重复启动或关闭应用；本版无取消功能。
4. 成功后点击“打开输出文件”或“打开所在文件夹”。首次转换生成 `原文件名_Micas.pptx` 和 `原文件名_Micas.report.json`；重复转换自动添加 `_2` 等后缀，不覆盖已有文件。
5. 点击“查看报告与风险”，检查风险和完整性结果，然后使用 PowerPoint 逐页复核。系统没有关联 PowerPoint 时，先安装适用的演示文稿软件，再手动打开文件。

## 失败与风险

- SmartArt、OLE、动画、连接线、组合对象、特殊图表等会阻止转换；报告中的 `warnings` 标明原始页和风险类别。桌面版不提供高风险转换开关。请保留原稿，让管理员评估；不要为了让转换通过而随意删掉对象。
- 文件损坏、加密、无目录写入权限、磁盘空间不足或模板校验失败时显示错误。修复原因后可重新选择文件重试。
- 成功生成不代表视觉验收通过。V1 复用现有规则式引擎，不能理解任意复杂版面。真实 4 页样稿测试曾出现 86 页过度拆分、组合图表失真等问题；本次桌面开发没有修复这些算法限制。用于对外材料前必须人工检查。
- 原文件不修改。报告与输出保存到用户选择的本地目录；引擎会将完整输入包归档进输出 PPTX，包含原始元数据和嵌入内容。向外分享前请检查内容。
- 应用本身不上传文件；若选择 OneDrive/iCloud/网络共享目录，操作系统或其他同步软件仍可能同步该目录，这不受本应用控制。

详细引擎范围见 [PPT 引擎说明](ppt-converter.md)。
