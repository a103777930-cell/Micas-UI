# Micas PPT 转换引擎 v0.1

这是无需模型 API 的规则式第一版，要求 Python 3.10+。输出为原生 PPTX，不将整页截图化。输入文件应来自可信来源；处理不可信上传时，应在隔离进程中设置 ZIP 解压大小、CPU、内存和超时限制，本版不提供公网上传服务。

## 安装和运行

在本仓库根目录：

```bash
python -m pip install -e .
micas-ppt input.pptx output.pptx --report output.report.json
# 未安装命令时也可：
python -m micas_ppt.cli input.pptx output.pptx
python -m unittest discover -s tests -v
python scripts/validate_templates.py
```

安装后若从其他位置使用，传 `--repo-root /path/to/Micas-UI` 指定含 catalog 和模板的仓库。模板不打包到 Python wheel。

CLI 成功返回 0，输入无效、模板哈希错误、检测到不支持对象或完整性失败返回 1。不支持对象会先写 JSON 报告并阻止生成；人工检查报告后可显式传 `--allow-risk` 尝试转换。该选项不意味着复杂对象获得完整支持。请不要覆盖已有业务输出；输入、输出、报告和官方模板不能使用相同路径。

供后续飞书任务调用的 Python 接口：

```python
from micas_ppt import convert
report = convert('input.pptx', 'output.pptx', 'report.json',
                 repo_root='/path/to/Micas-UI')
```

调用方负责上传下载、身份鉴权、任务隔离、重试和清理；本版未实现飞书连接器。

## 实现方案与实际支持

1. 从 `templates/catalog.json` 定位官方模板并校验 SHA-256；读取并记录 `layout-mapping.md` 的哈希。基于 v1 映射固定选择 L2、L5、L7、L15，检查 23 个版式结构。映射文件不是通用规则语言。
2. 在内存中复制官方文件，移除 15 张示例页，保留母版、全部版式、主题和品牌装饰。原始文件不重存、不改动。
3. 分析原生对象类型、文字段落、图片、表格、图表以及页面坐标。按从上到下、从左到右推断阅读顺序：标题单独放置；标题独页选封面；普通正文选单栏；两个较短独立对象选双栏；图片与短文字组合选图文。此规则不声称能理解任意页面的语义。
4. 原生对象 XML 复制到新页：文字保留 run、段落层级和超链接，再统一 Arial/微软雅黑、技术内容 Consolas，统一字号、段距与深灰品牌文字；表格保留合并单元格、原生格内容与格式；图表保留原生图表及嵌入工作簿；图片保持原裁剪和纵横比。普通形状保留原生几何。非文字对象不会转换为位图。
5. 长文本按文字容量估算、以完整段落为边界连续拆页，标题在续页重复，报告关联原页。不会为了拆页而切断代码段落。单个超长段落、过长标题、密集表格标记人工检查。技术识别是有限正则启发式，不保证识别全部代码和日志。
6. 复制依赖关系，并将完整输入包放入输出的 `micas-source/` 命名空间，保留原始媒体、图表、工作簿及未知部件，避免静默丢弃数据。归档部件不等于其内容已经显示在新页面，也不意味着复杂对象可用。输出可能显著增大，并保留输入包全部元数据和嵌入文件，分享前需要检查。备注关联保留；备注中的原始页链接不重新编号。
7. 输出保存到临时文件并重新打开，逐个文字节点计数比较，检查原生对象覆盖和图片/工作簿等二进制载荷逐字节一致，通过后发布输出。重复标题是预期行为。JSON 报告记录原页到新页映射、版式、对象 ID、风险、容量估算、越界、内容对象相交以及完整性结果。基础检测只覆盖生成页对象，不检测母版内部或组内碰撞。

## 明确限制

- SmartArt、OLE/嵌入对象、动画、切换效果、音视频、AlternateContent、组合对象、连接线拓扑和特殊图表默认阻止转换。显式接受风险后仅尽力保留对象 XML/依赖，动画与切换等页级行为不会应用到新页面。
- 仅常见柱形、条形、折线、饼图等原生图表作为可读取数据处理；不重新设计图表配色，不支持承诺特殊图表、宏、外链数据刷新或嵌入对象可编辑性。
- 输入母版、版式中的装饰及背景被官方样式替换，不将其作为源页对象提取；继承内容可能需要人工迁移。输入主题依赖对象可能改变外观。对象旋转、边框、艺术字、公式等复制后需要检查。
- 不执行 OCR，不修改截图内容；小字截图只是原图保留。表格字体不强制改小，不对合并表格自动切行拆页。
- 不做实际字体测量或渲染，没有 PowerPoint/LibreOffice 视觉验收。无法保证任意输入没有溢出或拥挤；报告标记问题并要求复核。状态 `completed_with_review_required` 表示结构转换完成，不能等同于视觉验收通过。
- 页级链接、评论、自定义放映及源页背景未迁移到新页序列。完整输入包归档用于保全数据，不能代替显示内容的人工验收。
- v1 没有模型语义分析或最优布局求解；章节、团队、目录、结束页专用语义暂未自动识别。

## 验证范围

自动测试构造中文长文、日志、表格、柱状图、图片和备注的真实 PPTX，检查连续拆页、多版式、文字完整性、图表数值、表格内容、备注、ZIP CRC、包内全部关系目标以及模板原件哈希。另测复杂对象阻断、风险显式放行、禁止覆盖输入。它们验证结构和数据，不验证 Office 渲染效果。
